# Accessibility plan

Target: WCAG 2.2 AA, with manual assistive-technology testing.

- Semantic headings and landmarks.
- Keyboard-operable controls and visible focus.
- Accessible names and instructions.
- Status messages announced using live regions.
- Text resize to 200% without loss of content/functionality.
- High contrast and no colour-only meaning.
- Speech output has repeat and stop controls.
- Speech input is optional; all workflows have non-voice paths.
- Test TalkBack, NVDA and VoiceOver with people with lived experience.

No accessibility audit or lived-experience test has yet been completed for this scaffold.
