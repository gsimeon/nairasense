# AI work area

No trained model is included.

Before model development:
1. Define consent and collection protocol.
2. Label denomination, side, series/design, orientation, condition, lighting, blur and obstruction.
3. Group splits by physical note and collection session.
4. Build a baseline and evaluate per-denomination precision/recall, macro F1, confusion matrix, high-confidence error rate, abstention and latency.
5. Publish model card and reproducible evaluation.

Do not represent the API mock response as model performance.
